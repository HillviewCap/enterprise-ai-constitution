# Changelog

All notable changes to the Enterprise AI Constitution Standard are documented here.

---

## [1.0.0] — 2026-03-30

### Added
- Initial release of the 9-section standard
- Corporate, team, and practitioner constitution templates
- 24-scenario test suite for constitution validation
- Manufacturing company example (anonymized)
- Context Onion framework documentation
- Deployment guide for enterprise environments

### Standard Sections
- 01 Identity
- 02 Organizational Context
- 03 Authority Limits
- 04 Data Classification (5-tier model: Public, Restricted, Confidential, Highly Confidential, Regulated)
- 05 Behavioral Mandates (Confidentiality, IP, Adversarial Code Review with supply chain awareness, Irreversible Actions, External Communications)
- 06 Misuse Detection (Personal use, Data exfiltration, Security bypass, Credentials, Prompt injection, Scorer of Record, Sycophantic Behavior)
- 07 Refusal Logic
- 08 Scope Limitations
- 09 Integrity Verification (optional module)
